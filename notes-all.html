Codierung & Modulation

Leitungscode

NRZ

Bei Non-Return-to-Zero werden 0 und 1 durch zwei konstante Pegel dargestellt. Innerhalb eines Bits muss kein Wechsel stattfinden.

Übergänge: 0->0: keiner, 1->1: keiner, 0->1: steigende Flanke, 1->0: fallende Flanke.
  • Einfach zu erzeugen und zu erkennen.
  • Lange Folgen gleicher Bits liefern kaum Taktinformation.
  • Kann einen Gleichanteil enthalten.
Leitungscode

Manchester

Bei Manchester gibt es in jedem Bitintervall einen Wechsel in der Mitte. Die Richtung des Wechsels kodiert den Bitwert.

Übergänge: Jedes Bit hat eine mittlere Flanke. Bei gleichen Nachbarbits gibt es zusätzlich eine Flanke an der Bitgrenze; bei wechselnden Bits nicht.
  • Gut für Taktrückgewinnung, weil jedes Bit einen Übergang hat.
  • Benötigt mehr Bandbreite als NRZ.
  • Wird oft als selbsttaktender Code beschrieben.
Leitungscode

MLT-3

Multi-Level-Transmit-3 nutzt drei Pegel: -1, 0 und +1. Eine 1 führt zum nächsten Pegel in der Folge, eine 0 hält den aktuellen Pegel.

Übergänge: 0: Pegel bleibt. 1: nächster Pegel in der Folge 0 -> +1 -> 0 -> -1 -> 0 -> ...
  • Reduziert die maximale Signalfrequenz gegenüber NRZ.
  • Allein nicht ideal bei langen Nullfolgen.
  • Wird deshalb gerne mit 4B5B kombiniert.
Blockcode

4B5B

4B5B bildet 4 Datenbits auf 5 Codebits ab. Die Codewörter werden so gewählt, dass genügend Übergänge entstehen und zusätzliche Kontrollsymbole möglich sind.

Übergänge: 4B5B erzeugt Codewörter mit mehr Übergängen als rohe Daten und begrenzt lange Nullfolgen; danach folgt häufig ein Leitungscode wie NRZI oder MLT-3.
  • Erhöht die Bitrate auf der Leitung um den Faktor 5/4.
  • Hilft gegen zu lange Folgen ohne Übergang.
  • Ist Codierung, nicht Modulation.
Modulation

ASK

Bei Amplitude Shift Keying wird die Amplitude des Trägersignals verändert. Unterschiedliche Amplituden stehen für unterschiedliche Symbole.

Veränderung: Die Amplitude wechselt; Frequenz und Phase bleiben im einfachen Modell gleich.
  • Einfaches Prinzip.
  • Empfindlich gegenüber Amplitudenrauschen.
  • 2-ASK hat zwei unterscheidbare Amplituden.
Modulation

PSK

Bei Phase Shift Keying wird die Phase des Trägersignals verändert. Die Amplitude kann dabei konstant bleiben.

Veränderung: Die Phase springt zwischen Symbolpunkten; bei 2-PSK typischerweise um 180 Grad.
  • 2-PSK nutzt zwei Phasenlagen.
  • Mehr Phasenlagen bedeuten mehr Bits pro Symbol.
  • Die Punkte liegen im Signalraum oft auf einem Kreis.
Modulation

QAM

Quadrature Amplitude Modulation verändert zwei orthogonale Komponenten: I und Q. Dadurch werden Amplitude und Phase kombiniert genutzt.

Veränderung: Symbolwechsel können I, Q, Amplitude und Phase verändern. 16-QAM hat 16 Signalraumpunkte.
  • M-QAM überträgt log2(M) Bits pro Symbol.
  • 16-QAM überträgt 4 Bits pro Symbol.
  • Höhere Ordnung braucht besseres SNR.
Prüfungstipp

Schnelle Unterscheidung

NRZ, Manchester, MLT-3 und 4B5B sind Leitungscodierungs- bzw. Blockcodierungsverfahren. Sie beschreiben, wie Bits auf Leitungssignale oder Codewörter abgebildet werden. ASK, PSK und QAM sind Modulationsverfahren. Sie beschreiben, welche Eigenschaft eines Trägersignals verändert wird.

IPv6 Address Notes

Grundstruktur

Prefix /64 + Interface ID /64

Eine IPv6-Adresse besteht in Aufgaben meistens aus zwei Teilen.

Prefix /64 + Interface ID /64

2001:db8:1::/64 + abcd:1234:5678:9999

Der Prefix beschreibt das Netzwerk. Die Interface ID identifiziert das Gerät bzw. Interface innerhalb dieses Netzwerks.

Methode 1

SLAAC mit Modified EUI-64

Verwende diese Methode, wenn die Aufgabe eine MAC-Adresse gibt und automatische IPv6-Erzeugung erwartet. 

1. MAC nehmen
   04:7b:cb:c1:08:06

2. In der Mitte teilen
   04:7b:cb | c1:08:06

3. ff:fe einfügen
   04:7b:cb:ff:fe:c1:08:06

4. U/L-Bit im ersten Byte flippen
   04 -> 06

5. Prefix ergänzen
   fe80::/64 für link-local
   oder gegebenen globalen Prefix

Ergebnis mit Link-Local Prefix:

fe80::67b:cbff:fec1:806
Merke: U/L bit flip = first byte XOR 0x02. Beispiele: 00 -> 02, 04 -> 06, c0 -> c2, a6 -> a4.
Methode 2

SLAAC mit gegebenem Prefix

Wenn die Interface ID bereits gegeben ist, hängst du sie nur an den Prefix an. 

Interface ID = 067b:cbff:fec1:0806
Prefix       = 2001:db8:1::/64

Adresse:
2001:db8:1::67b:cbff:fec1:806

Link-local:
fe80::67b:cbff:fec1:806
Methode 3

Manuell gesetzte IPv6-Adresse

Manchmal gibt die Aufgabe einfach eine gewählte Adresse an oder erwartet eine typische manuelle Konfiguration, besonders bei Routern und Servern. 

Router interface:
2001:db8:1::1/64

Dafür brauchst du kein EUI-64.

Methode 4

DHCPv6

Bei DHCPv6 weist ein Server die IPv6-Adresse zu. Du berechnest sie nicht aus der MAC-Adresse, außer die Aufgabe gibt eine DHCP-Tabelle. 

DHCPv6 = Server gibt Adresse
SLAAC  = Host baut Adresse selbst
Methode 5

Privacy / Random Interface ID

Moderne Systeme verwenden oft keine MAC-basierte EUI-64-Adresse, sondern eine zufällig wirkende Interface ID. 

2001:db8:1::8f3a:91ff:bc22:1009

Wenn die Interface ID nicht zur MAC passt, kann sie random/privacy, manuell oder per DHCPv6 vergeben sein.

Layers & Encapsulation

Theory Notes

Theory Questions and Answers

Question

Explain why computer networks are described with layered models. What is gained by separating services, interfaces, and protocols?

Layering reduces complexity. Each layer offers a service to the layer above, uses services from the layer below, and communicates with its peer by a protocol. This lets Ethernet, IP, TCP, DNS, HTTP, etc. evolve independently as long as the interfaces remain compatible.

Question

Define PDU, SDU, PCI, and ICI.

  • PCI: header/trailer, i.e. protocol control information added by the layer.
  • SDU: payload/data handed down from an upper layer.
  • PDU: complete thing at that layer, usually PCI + SDU.
  • ICI: local interface control information between adjacent layers, normally not transmitted.
Merksatz: PCI = header/trailer, SDU = payload/data, PDU = complete thing at that layer.
Question

In the ISO/OSI model, name the main responsibility of each layer from physical to application layer.

  • L1 Physical: bits/signals
  • L2 Data Link: frames, Ethernet, MAC addressing, direct-link access, error detection
  • L3 Network: IPv4, IPv6, ICMP, logical addressing, routing
  • L4 Transport: TCP, UDP, end-to-end transport between processes
  • L5 Session: session management in the OSI model
  • L6 Presentation: representation, encryption, compression
  • L7 Application: DNS, HTTP and other application protocols

Question

Distinguish horizontal communication from vertical communication.

Horizontal communication is logical peer communication between the same layer on different hosts. Vertical communication is real local interaction between neighboring layers in the same host.

Question

For Ethernet, IPv4, and TCP, which layer adds which header?

  • Application data: payload handed to TCP.
  • TCP: adds a TCP header, producing a TCP segment.
  • IPv4: adds an IP header, producing an IP packet.
  • Ethernet: adds Ethernet header and FCS, producing an Ethernet frame.
  • Ethernet payload: the whole IP packet is the L2 payload.
Question

Explain host byte order versus network byte order.

Host byte order depends on the CPU architecture. Network byte order is big-endian and is used in protocol fields so all machines interpret multi-byte numbers consistently.

Question

Classify Ethernet, ARP, IPv4, IPv6, ICMP, UDP, TCP, DNS, HTTP, and TLS by layer.

  • L1 Physical: bits/signals
  • L2 Data Link: Ethernet, MAC
  • L2/L3 helper: ARP for IPv4 address resolution on the local link
  • L3 Network: IPv4, IPv6, ICMP/ICMPv6, routing
  • L4 Transport: TCP, UDP
  • L7 Application: DNS, HTTP
  • TLS: between transport and application; often described as session/presentation functionality in OSI terms
Question

How do you analyze a hexdump?

  • Start at byte 0.
  • Ethernet: read 6 B destination MAC, 6 B source MAC, 2 B Ethertype.
  • Ethertype: 0x0800 IPv4, 0x86dd IPv6, 0x0806 ARP.
  • IPv4: use IHL to find the L3 header length.
  • IPv6: base header is 40 B; use Next Header.
  • L4: use Protocol/Next Header to locate TCP, UDP, or ICMP.

Physical Layer

Theory Notes

Theory Questions and Answers

Question

Define signal, symbol, information content, entropy, conditional entropy, and joint entropy.

A signal is a measurable physical quantity over time. A symbol is a defined signal state or change that represents information. Information content is I(x)=-_2 p(x). Entropy is average information H(X)=_x p(x)I(x). Conditional entropy measures remaining uncertainty when another variable is known. Joint entropy measures uncertainty of a pair of random variables.

Question

Why does a rare symbol carry more information?

A rare symbol is less predictable, so observing it resolves more uncertainty. Since -_2 p(x) grows when p(x) becomes smaller, rare symbols have higher information content.

Question

When is entropy maximal?

Entropy is maximal when all symbols are equally likely. A binary source has maximum entropy 1 bit at p(0)=p(1)=0.5. An alphabet of M equally likely symbols has entropy _2 M bits per symbol.

Question

Distinguish time/value continuity.

  • Time-continuous: defined for every time instant.
  • Time-discrete: defined only at sample instants.
  • Value-continuous: arbitrary amplitudes are possible.
  • Value-discrete: only fixed amplitude levels are possible.
  • Sampled but unquantized: time-discrete and value-continuous.
  • Digital bit stream: time-discrete and value-discrete.
Question

Fourier series or Fourier transform?

Fourier series represents periodic signals as sums of harmonics. Fourier transform represents general aperiodic signals in the frequency domain. Use Fourier series when the signal is periodic or constructed by periodic repetition of a ground pulse.

Question

State the sampling theorem.

A signal bandlimited to B can be reconstructed from samples if f_A 2B. Below that, aliasing occurs: high-frequency components appear as wrong lower-frequency components and information is lost.

Question

Sampling versus quantization?

Sampling discretizes time. Quantization discretizes amplitude. For linear quantization over interval [a,b] with M levels, the step width is approximately =(b-a)/(M-1) for levels including both endpoints; with rounding, the maximum error inside the interval is about /2.

Question

Explain SNR and dB conversion.

Linear SNR=P_S/P_N. In dB, SNR_dB=10_10(SNR). Convert back by SNR=10^SNR_dB/10.

Question

Compare Hartley and Shannon-Hartley capacity.

Hartley depends on bandwidth and the number of distinguishable signal levels. Shannon-Hartley depends on bandwidth and noise: C=B_2(1+SNR). Hartley focuses on symbol distinguishability; Shannon gives a noise-limited upper bound.

Question

Source coding, channel coding, line coding?

  • Source coding: removes redundancy, e.g. Huffman compression.
  • Channel coding: adds structured redundancy for error detection/correction.
  • Line coding: maps bits or code words to physical signal shapes suitable for the medium.
Question

Manchester, NRZ, MLT-3, ASK, PSK, and QAM?

  • NRZ: line code.
  • Manchester: line code with a transition in every bit interval.
  • MLT-3: multi-level line code.
  • ASK: changes amplitude.
  • PSK: changes phase.
  • QAM: uses amplitude in two quadrature components and is often visualized as a constellation.
Question

For M-QAM, how many bits are transmitted per symbol?

  • General rule: log2(M) bits per symbol.
  • 16-QAM: 4 bits/symbol.
  • 32-QAM: 5 bits/symbol.
  • 1024-QAM: 10 bits/symbol.
Question

Why does higher-order modulation need better SNR?

More constellation points are closer together, so noise can more easily move a received point across a decision boundary. Better SNR is needed to distinguish symbols reliably.

Question

Compare electrical, optical, and wireless media.

  • Electrical copper: cheap and common, but affected by attenuation and electromagnetic interference.
  • Optical fiber: high rates, long distances, immune to electromagnetic interference.
  • Wireless: flexible and mobile, but shared, noisy, and collision/interference-prone.
Question

Propagation delay versus serialization delay?

Propagation delay is travel time through the medium: t_p=d/v. Serialization delay is time to put all bits on the link: t_s=L/R. Long distances increase propagation delay; large frames or low bitrates increase serialization delay.

Data Link Layer

Theory Notes

Theory Questions and Answers

Question

What are the main tasks of the data link layer?

It handles communication over one direct link or broadcast domain: framing, L2 addressing, medium access control, and error detection such as FCS/CRC.

Question

Why is medium access control needed?

On shared media, multiple stations can transmit at the same time. MAC rules coordinate access so collisions are avoided, detected, or recovered from.

Question

Compare ALOHA, slotted ALOHA, CSMA, CSMA/CD, and CSMA/CA.

  • ALOHA: sends without sensing and relies on retransmission.
  • Slotted ALOHA: only starts transmissions at slot boundaries.
  • CSMA: senses the channel before sending.
  • CSMA/CD: detects collisions while transmitting and aborts.
  • CSMA/CA: tries to avoid collisions with backoff and acknowledgements, useful for WLAN.
Question

Why classic Ethernet CSMA/CD but WLAN CSMA/CA?

A wired Ethernet sender can listen while sending and detect a collision. A WLAN sender cannot reliably hear collisions while transmitting and hidden terminals exist, so WLAN reduces collision probability and uses ACKs.

Question

Define collision domain and broadcast domain.

  • Collision domain: nodes whose simultaneous transmissions can collide.
  • Broadcast domain: nodes receiving an L2 broadcast.

Question

How does a switch learn and forward?

  • Learns source MAC to ingress port mappings.
  • For a known destination, forwards only to the learned port.
  • For an unknown unicast or broadcast, floods to all other ports.
Question

Why are switches transparent but WLAN APs explicitly addressed?

Ethernet hosts send frames directly to the final L2 peer; switches forward without changing source/destination MAC. In WLAN, the AP participates in the wireless frame exchange, so wireless frames include AP-related transmitter/receiver addresses.

Question

Why can WLAN frames contain three MAC addresses?

WLAN needs to distinguish wireless receiver/transmitter from the original source/final destination across the distribution system. Ethernet usually needs only destination and source MAC.

Question

What are the Ethernet frame fields?

  • Destination MAC: 6 B
  • Source MAC: 6 B
  • Ethertype/Length: 2 B
  • Payload: usually up to 1500 B
  • FCS: 4 B
  • Preamble and inter-frame gap: physical/on-wire overhead, normally not counted as MAC frame length in exam calculations.
Question

What does Ethernet MTU 1500 B include?

  • Maximum L3 packet size inside the Ethernet payload.
  • Includes IP header, transport header, and transport/application data.
  • Excludes Ethernet header and FCS.
  • Usual maximum Ethernet frame: 14 + 1500 + 4 = 1518 B.
Question

Explain ARP.

ARP maps an IPv4 address in the local L2 network to a MAC address. The request is sent to broadcast MAC ff:ff:ff:ff:ff:ff; the reply is normally unicast back to the requester.

Question

Explain CRC.

The sender treats the bit string as a polynomial, divides by a reduction polynomial, and appends the remainder as checksum. The receiver divides message plus checksum by the same polynomial; a zero remainder indicates no detected error.

Question

Why is CRC not error correction?

CRC detects many error patterns but does not identify the exact bit positions to repair. It is primarily error detection, not correction.

Question

Store-and-forward versus cut-through switching?

Store-and-forward receives the whole frame and can verify FCS before forwarding. Cut-through begins forwarding once the output port is known, reducing latency but possibly forwarding corrupted frames.

Question

In mixed hub/switch/AP topologies, how do you pick MAC addresses?

For Ethernet over switches, source/destination MAC stay the sender/final L2 receiver inside the broadcast domain. Across WLAN, the AP may be the receiver/transmitter address on the wireless hop. Across routers, the L2 addresses change per hop.

Network Layer

Theory Notes

Theory Questions and Answers

Question

Why is the network layer needed even with Ethernet switching?

Ethernet MAC addresses are flat and local to a broadcast domain. The network layer provides logical hierarchical addressing, subnetting, routing across multiple links, and interconnection of different L2 networks.

Question

Compare circuit, message, and packet switching.

  • Circuit switching: reserves a path before transmission.
  • Message switching: forwards complete messages hop by hop.
  • Packet switching: splits data into packets with headers, allowing multiplexing and independent forwarding.
Question

Forwarding versus routing?

Forwarding is the local action of sending one packet to the selected next hop/interface. Routing is the process of building the routing table and deciding which paths should be used.

Question

Explain IPv4 prefix, network address, broadcast address, and usable host range.

  • Prefix length: number of leading bits that identify the network.
  • Network address: host bits are all 0.
  • Broadcast address: host bits are all 1.
  • Usable host range: normally between network and broadcast, excluding both.
Question

How do you compute IPv4 subnet information?

  1. Apply the subnet mask to the IP address to get the network address.
  2. Set all host bits to 1 to get the broadcast address.
  3. First usable address is normally network plus one.
  4. Last usable address is normally broadcast minus one.
  5. Watch for special assumptions such as point-to-point /31.
Question

Explain longest-prefix matching.

A router chooses the matching route with the most specific prefix, i.e. the largest prefix length. Only if specificity ties do metrics/administrative preferences become relevant.

Question

Important IPv4 header fields?

  • Version: identifies IPv4.
  • IHL: gives the IPv4 header length.
  • Total Length: gives the complete IPv4 packet size.
  • Identification, Flags, Fragment Offset: support fragmentation.
  • TTL: limits packet lifetime across routers.
  • Protocol: selects L4/ICMP, e.g. TCP, UDP, ICMP.
  • Header Checksum: protects the IPv4 header.
  • Source/Destination: end-to-end IP addresses.
Question

Explain IPv4 fragmentation.

  • If an IPv4 packet exceeds the outgoing MTU and DF is not set, a router may split it.
  • All fragments share the same Identification value.
  • Fragment Offset is measured in 8-byte units.
  • MF is set on all fragments except the last.
  • Fragment payload, except the last fragment, must be a multiple of 8 bytes.
Question

MTU, path MTU, IP packet size, segment size, application payload?

  • MTU: maximum L3 packet size on one L2 link.
  • Path MTU: minimum MTU along the whole path.
  • IP packet size: IP header plus IP payload.
  • TCP segment size: TCP header plus TCP payload.
  • Application payload: what remains after IP and transport headers.
Question

Explain IPv6 address concepts.

IPv6 addresses are 128 bits. Leading zeroes in each 16-bit group may be omitted. One longest run of zero groups may be compressed with ::. Link-local addresses start with fe80::/10. Global unicast addresses are globally routable. Solicited-node multicast is used by Neighbor Discovery.

Question

ARP versus Neighbor Discovery?

ARP maps IPv4 addresses to MAC addresses using L2 broadcast. IPv6 uses ICMPv6 Neighbor Solicitation and Neighbor Advertisement, usually sent to solicited-node multicast rather than broadcast.

Question

Explain SLAAC.

Stateless Address Autoconfiguration lets a host create its own IPv6 address from an advertised prefix plus an interface identifier. Privacy extensions randomize/change interface identifiers to reduce tracking.

Question

IPv4 versus IPv6 fragmentation?

  • IPv4: routers may fragment packets if DF is not set.
  • IPv6: routers do not fragment normal packets.
  • IPv6 source host: must send suitably sized packets or use the IPv6 Fragment extension header.
Question

ICMP/ICMPv6 messages?

Echo Request/Reply support ping-style reachability tests. TTL/Hop-Limit exceeded is sent when a router decrements TTL/Hop Limit to zero. ICMP also carries error information such as destination unreachable or packet too big.

Question

Static, distance-vector, link-state, and path-vector routing?

  • Static: routes are configured manually.
  • Distance-vector: routers exchange distances to destinations.
  • Link-state: routers flood topology information and compute shortest paths.
  • Path-vector: protocols advertise paths, e.g. AS paths in BGP.
Question

Count-to-infinity?

It is a distance-vector failure mode where routers slowly increase a metric due to stale mutual information. Split horizon avoids advertising a route back where it was learned; path-vector carries the path so loops can be detected.

Question

Explain AS relationships and BGP policy.

An AS is a network under one administrative control. Customer/provider/peer relationships affect which routes are announced. Providers sell transit, customers buy transit, peers exchange traffic between their own/customer networks. BGP is policy-driven, not just shortest-path routing.

Routing

What is a Tier-1 autonomous system?

A Tier-1 autonomous system is at the top level of the Internet routing hierarchy. It can reach every other network on the Internet without buying transit from another provider.

Theory Questions and Answers

Question

Compare UDP and TCP.

  • UDP: connectionless, datagram-oriented, unreliable, no ordering guarantee.
  • TCP: connection-oriented, stream-oriented, reliable, ordered, with flow and congestion control.
Question

Why can UDP datagrams arrive out of order?

IP packets may take different paths or experience different delays, and UDP does not reorder or retransmit. TCP numbers bytes and delivers them to the application in order.

Question

Explain the TCP three-way handshake.

  1. Client sends SYN with its initial sequence number.
  2. Server replies SYN-ACK with its own sequence number and acknowledgement of the client SYN.
  3. Client sends ACK.
  4. MSS may be announced as a TCP option during the SYN exchange.
Question

How do you compute MSS from MTU?

  • MSS: maximum TCP payload, not the full IP packet.
  • IPv4 without options on Ethernet: 1500 - 20 - 20 = 1460 B.
  • TCP options: subtract them if present.
  • IPv6 without extension headers: 1500 - 40 - 20 = 1440 B.
Question

Explain TCP teardown.

Each direction is closed independently with FIN and ACK. A common graceful close is FIN, ACK, FIN, ACK, though FINs can sometimes be combined with data/ACKs.

Question

Explain TCP congestion control.

  • The sender controls a congestion window to avoid overloading the network.
  • Slow start: increases quickly.
  • Congestion avoidance: increases more cautiously.
  • Packet loss: reduces the window.
  • Goal: network stability and fair sharing.
Question

Explain NAT/PAT.

NAT rewrites IP addresses; PAT additionally rewrites transport ports so many internal hosts can share one public IP. The NAT table maps internal tuple to external tuple and uses it to translate replies.

Question

Why is NAT harder for ICMP?

TCP/UDP have ports that identify flows. ICMP often lacks ports; error messages may include part of the original packet, so the NAT must inspect embedded headers to find the internal flow.

Question

Explain UDP hole punching.

  1. Both peers send outbound UDP packets so their NATs create mappings.
  2. A coordination server tells each peer the other peer's public endpoint.
  3. Incoming packets can then match existing NAT state.

TCP/UDP Checksums Are Not Security Integrity

Use this in the exam by first naming the goal, then saying which mechanism provides it. Example: TCP provides reliability through sequence numbers, ACKs, retransmissions, and ordered delivery. TLS provides confidentiality, integrity, and authenticity through cryptographic protection and certificates.
