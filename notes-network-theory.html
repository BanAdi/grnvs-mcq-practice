Theory Questions and Answers

Question

Why is the network layer needed even with Ethernet switching?

Ethernet MAC addresses are flat and local to a broadcast domain. The network layer provides logical hierarchical addressing, subnetting, routing across multiple links, and interconnection of different L2 networks.

Question

Compare circuit, message, and packet switching.

Circuit switching reserves a path before transmission. Message switching forwards complete messages hop by hop. Packet switching splits data into packets, each with a header, allowing multiplexing and independent forwarding.

Question

Forwarding versus routing?

Forwarding is the local action of sending one packet to the selected next hop/interface. Routing is the process of building the routing table and deciding which paths should be used.

Question

Explain IPv4 prefix, network address, broadcast address, and usable host range.

The prefix length says how many leading bits identify the network. The network address has host bits all 0. The broadcast address has host bits all 1. Usable host addresses are normally between them, excluding network and broadcast.

Question

How do you compute IPv4 subnet information?

Apply the subnet mask to the IP address to get the network. Set all host bits to 1 for broadcast. First usable is network plus one; last usable is broadcast minus one, except for special cases such as point-to-point /31 depending on assumptions.

Question

Explain longest-prefix matching.

A router chooses the matching route with the most specific prefix, i.e. the largest prefix length. Only if specificity ties do metrics/administrative preferences become relevant.

Question

Important IPv4 header fields?

Version identifies IPv4, IHL gives header length, Total Length gives packet size, Identification/Flags/Fragment Offset support fragmentation, TTL limits lifetime, Protocol selects L4/ICMP, Header Checksum protects the IPv4 header, and source/destination are end-to-end IP addresses.

Question

Explain IPv4 fragmentation.

If an IPv4 packet exceeds the outgoing MTU and DF is not set, a router may split it. All fragments share Identification. Fragment Offset is in 8-byte units. MF is set on all fragments except the last. Fragment payload except the last must be a multiple of 8 bytes.

Question

MTU, path MTU, IP packet size, segment size, application payload?

MTU is the maximum L3 packet size on one L2 link. Path MTU is the minimum MTU along the path. IP packet size includes IP header plus IP payload. TCP segment size includes TCP header plus TCP payload. Application payload is what remains after IP and transport headers.

Question

Explain IPv6 address concepts.

IPv6 addresses are 128 bits. Leading zeroes in each 16-bit group may be omitted. One longest run of zero groups may be compressed with ::. Link-local addresses start with fe80::/10. Global unicast addresses are globally routable. Solicited-node multicast is used by Neighbor Discovery.

Question

ARP versus Neighbor Discovery?

ARP maps IPv4 addresses to MAC addresses using L2 broadcast. IPv6 uses ICMPv6 Neighbor Solicitation and Neighbor Advertisement, usually sent to solicited-node multicast rather than broadcast.

Question

Explain SLAAC.

Stateless Address Autoconfiguration lets a host create its own IPv6 address from an advertised prefix plus an interface identifier. Privacy extensions randomize/change interface identifiers to reduce tracking.

Question

IPv4 versus IPv6 fragmentation?

IPv4 routers may fragment packets. IPv6 routers do not fragment normal packets; the source must send suitably sized packets or use the IPv6 Fragment extension header.

Question

ICMP/ICMPv6 messages?

Echo Request/Reply support ping-style reachability tests. TTL/Hop-Limit exceeded is sent when a router decrements TTL/Hop Limit to zero. ICMP also carries error information such as destination unreachable or packet too big.

Question

Static, distance-vector, link-state, and path-vector routing?

Static routes are configured manually. Distance-vector routers exchange distances to destinations. Link-state routers flood topology information and compute shortest paths. Path-vector protocols advertise paths, e.g. AS paths in BGP.

Question

Count-to-infinity?

It is a distance-vector failure mode where routers slowly increase a metric due to stale mutual information. Split horizon avoids advertising a route back where it was learned; path-vector carries the path so loops can be detected.

Question

Explain AS relationships and BGP policy.

An AS is a network under one administrative control. Customer/provider/peer relationships affect which routes are announced. Providers sell transit, customers buy transit, peers exchange traffic between their own/customer networks. BGP is policy-driven, not just shortest-path routing.

Old Exam Questions and Answers

Midterm 2020, Aufgabe 1

Question: Which IP and MAC destination are used when sending to another host? Answer: The IP destination is the final host; the MAC destination is the next L2 receiver on the current link, e.g. gateway/AP/final host depending on topology.

Endterm 2022, Aufgabe 1

Question: How long is an IPv6 address and how are link-local addresses shortened? Answer: IPv6 is 128 bits; remove leading zeroes per group and compress one longest zero run with ::.

Endterm 2022, Aufgabe 4

Question: Send ICMP Echo through a residential IPv4 network. Answer: ARP is needed for each next-hop MAC if caches are empty; L2 MACs change at each hop; IP source/destination stay end-to-end; TTL decreases per router.

Endterm 2022, Aufgabe 5

Question: Interpret Ethernet + IPv4 + TCP/SMTP frame. Answer: Ethertype 0x0800 means IPv4, IHL 5 means 20 B IPv4 header, Protocol 0x06 means TCP, TCP destination port 25 means SMTP.

Endterm 2023, Aufgabe 2

Question: Configure IP routing in a lab topology. Answer: Assign addresses from the correct prefixes, set gateways/routes so each destination has a next hop, and remember routers separate broadcast domains.

Endterm 2023, Aufgabe 3

Question: MC on domains and addressing. Answer: Switches split collision domains, routers split broadcast domains, and IP routing is required across subnets.

Endterm 2024, Aufgabe 3

Question: Use longest-prefix matching in a routing table. Answer: Select the route with the longest matching prefix; UDP likely explains out-of-order chat messages because UDP provides no ordering guarantee.

Endterm 2024, Aufgabe 4

Question: Analyze an IPv6/TCP hexdump. Answer: IPv6 base header is 40 B; Next Header 0x06 is TCP; Hop Limit is decremented by routers; source/destination IPv6 addresses occupy 16 B each.

Endterm 2025, Aufgabe 2

Question: IPv6 Wohnheim network with empty caches. Answer: Hosts use NDP to learn MAC addresses, can form addresses from prefix plus interface identifier when SLAAC applies, and send off-link traffic to the gateway.

Endterm 2025, Aufgabe 3

Question: Identify ICMP in a frame. Answer: IPv4 Protocol 1 identifies ICMP; ICMP type/code state whether it is Echo, TTL exceeded, unreachable, etc.

Retake 2022, Aufgabe 1

Question: Which routes does one AS announce to a peer? Answer: An AS typically announces its own and customer prefixes to peers/providers, but not routes learned from one peer/provider to another peer/provider.

Retake 2022, Aufgabe 2

Question: Give IPv4 PTR name and detect invalid subnet. Answer: Reverse IPv4 uses reversed octets under in-addr.arpa; e.g. 203.0.113.4 becomes 4.113.0.203.in-addr.arpa. A subnet address must have host bits zero.

Retake 2022, Aufgabe 6

Question: IPv4 network with NAT. Answer: NAT rewrites private source IP/port to public IP/port on outgoing packets and uses its mapping table for incoming replies.

Retake 2023, Aufgabe 5

Question: Home network with NAT-capable router. Answer: Inside hosts use private addresses and default route to the NAT router; the router translates addresses/ports for Internet traffic.

Retake 2023, Aufgabe 6

Question: MTU and maximum Ethernet frame size. Answer: MTU 1500 B is L3 packet size; Ethernet frame with header and FCS is 1518 B. Propagation and serialization are separate delays.

Retake 2024, Aufgabe 3

Question: Fill source/destination MAC and IP at points across NAT. Answer: MACs change every hop; IP destination is rewritten by NAT when entering the private side; public-to-private mapping determines the final private IP/port.

Retake 2024, Aufgabe 7

Question: Derive IPv6 solicited-node address and multicast MAC. Answer: Use last 24 bits of the IPv6 address: solicited-node is ff02::1:ffXX:XXXX; Ethernet multicast MAC is 33:33:ff:XX:XX:XX.

Retake 2025, Aufgabe 1

Question: Which IPv6 address is fully shortened? Answer: Remove all leading zeroes and compress exactly one longest zero run; do not use :: twice.

Retake 2025, Aufgabe 3

Question: Forward IPv4 packets across routers. Answer: Each router forwards based on LPM, decrements TTL, and sends the packet in a new L2 frame to the next-hop MAC.

Retake 2025, Aufgabe 5

Question: IPv4, UDP, and NAT hole punching. Answer: UDP hole punching relies on both peers creating NAT mappings by sending outbound packets, so later inbound packets match existing NAT table entries.

Exam Answer Checklist

Checklist

Exam Answer Checklist

  • L2 addresses change at every hop; L3 source/destination normally stay end-to-end unless NAT is involved.
  • TTL/Hop Limit decreases by one at each router.
  • IPv4 routers may fragment; IPv6 routers do not fragment normal packets. IPv6 uses source fragmentation plus Fragment extension header.
  • Fragment offset is counted in 8-byte units.
  • Longest-prefix match beats lower metric among less-specific alternatives.
  • IPv6 abbreviation: remove leading zeroes in groups and compress one longest all-zero run with ::; use :: at most once.
