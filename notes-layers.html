Theory Questions and Answers

Question

Explain why computer networks are described with layered models. What is gained by separating services, interfaces, and protocols?

Layering reduces complexity. Each layer offers a service to the layer above, uses services from the layer below, and communicates with its peer by a protocol. This lets Ethernet, IP, TCP, DNS, HTTP, etc. evolve independently as long as the interfaces remain compatible.

Question

Define PDU, SDU, PCI, and ICI.

The SDU is the payload handed down from an upper layer. The PDU is the complete unit of a layer: usually PCI plus SDU. PCI is protocol control information such as headers/trailers used by peer entities. ICI is interface control information used locally between adjacent layers and is normally not transmitted.

Question

In the ISO/OSI model, name the main responsibility of each layer from physical to application layer.

L1 transmits signals/bits. L2 frames data on a direct link, handles MAC addressing and error detection. L3 provides logical addressing and routing. L4 provides end-to-end transport such as UDP/TCP. L5 handles sessions, L6 representation/encryption/compression, and L7 application protocols.

Question

Distinguish horizontal communication from vertical communication.

Horizontal communication is logical peer communication between the same layer on different hosts. Vertical communication is real local interaction between neighboring layers in the same host.

Question

For Ethernet, IPv4, and TCP, which layer adds which header?

TCP adds a TCP header to application data, producing a TCP segment. IPv4 adds an IP header, producing an IP packet. Ethernet adds an Ethernet header and FCS, producing an Ethernet frame. For Ethernet, the whole IP packet is L2 payload.

Question

Explain host byte order versus network byte order.

Host byte order depends on the CPU architecture. Network byte order is big-endian and is used in protocol fields so all machines interpret multi-byte numbers consistently.

Question

Classify Ethernet, ARP, IPv4, IPv6, ICMP, UDP, TCP, DNS, HTTP, and TLS by layer.

Ethernet is L2. ARP sits between L2 and L3 for IPv4 address resolution. IPv4, IPv6, and ICMP/ICMPv6 are network-layer related. UDP and TCP are L4. DNS and HTTP are application protocols. TLS is commonly between transport and application and can be described as session/presentation-layer functionality in OSI terms.

Question

How do you analyze a hexdump?

Start at byte 0. For Ethernet, read 6 B destination MAC, 6 B source MAC, 2 B Ethertype. Ethertype tells you the L3 parser, e.g. 0x0800 IPv4, 0x86dd IPv6, 0x0806 ARP. Then use IPv4 IHL or IPv6 fixed header and Next Header/Protocol to locate L4.

Old Exam Questions and Answers

Midterm 2021, Aufgabe 1

Question: Which terms describe the payload/control units around layer 3? Answer: The L3 PDU is a packet. The L3 SDU is the payload received from above before the L3 header is added.

Midterm 2020, Aufgabe 1

Question: Which OSI layer does ICMP belong to? Answer: ICMP is network-layer related, i.e. layer 3, because it reports IP-layer control and error information.

Retake 2024, Aufgabe 1

Question: Interpret a hex value under byte-order conventions. Answer: Network byte order is big-endian; little-endian stores the least significant byte first.

Endterm 2022, Aufgabe 5

Question: Identify Ethernet, IPv4, TCP, and payload fields in a hexdump. Answer: Use Ethertype 0x0800 for IPv4, IPv4 IHL for L3 header length, Protocol 0x06 for TCP, TCP data offset for L4 header length, then the remaining bytes are payload.

Endterm 2023, Aufgabe 1

Question: Reconstruct a frame from topology and protocol facts. Answer: L2 source/destination MAC addresses are for the current hop; IP source/destination remain the original endpoints; header lengths and checksums determine offsets and missing bytes.

Retake 2023, Aufgabe 2

Question: Analyze an Ethernet/IPv6/TCP hexdump. Answer: Ethertype 0x86dd selects IPv6; IPv6 has a fixed 40 B base header; Next Header 0x06 means TCP.

Endterm 2024, Aufgabe 4

Question: Identify Ethernet/IPv6 fields and derive embedded addresses. Answer: Read Ethernet addresses first, then IPv6 version/traffic class/flow label, payload length, next header, hop limit, source and destination addresses.

Endterm 2025, Aufgabe 3

Question: Analyze an Ethernet frame carrying ICMP. Answer: Ethertype 0x0800 gives IPv4; IPv4 Protocol 0x01 gives ICMP; ICMP type/code identify the concrete ICMP message.

Exam Answer Checklist

  • PDU of layer N becomes SDU of layer N-1.
  • PCI is the header/trailer added for peer communication at the same layer.
  • Network byte order is big-endian.
  • In hexdumps, first use fixed fields: Ethernet destination/source/type, then IP version/IHL or IPv6 fixed header, then protocol/next-header.
